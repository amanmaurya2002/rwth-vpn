RWTH VPN

A small VPN client for RWTH Aachen.

CLI first · Apple Silicon · macOS 26+ · credentials stay in your Keychain.

Install CLI Documentation Free · MIT

Unofficial student project. Not affiliated with RWTH Aachen University or its IT Center. The supported client is Cisco Secure Client.

Install the CLI

Recommended. No Homebrew and no app download required.

curl -fsSL https://raw.githubusercontent.com/amanmaurya2002/rwth-vpn/main/install.sh | bash

Then run rwth-vpn setup and rwth-vpn connect. Setup asks for administrator authorization once to install the VPN helper.

Experimental desktop app

The native app provides a menu bar interface, but it is not notarized and requires macOS's Open Anyway approval.

Download app Installation guide

CLI basics

  • Configure credentials in the desktop app first; the CLI uses the same Keychain entries.
  • rwth-vpn status shows helper and tunnel state.
  • rwth-vpn uninstall removes the CLI and helper; add --purge to remove credentials too.

Why

The CLI keeps the workflow small: install one script, authorize the helper once, and connect from the terminal. Split tunnel is the default, so your local network keeps working.
