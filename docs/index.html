RWTH VPN

A tiny native VPN client for RWTH Aachen.

Apple Silicon · macOS 14+ · password and token stay in your Keychain.

Download Install guide Free · MIT · 5 MB

Unofficial student project. Not affiliated with RWTH Aachen University or its IT Center. The supported client is Cisco Secure Client.

Install

  1. Download the DMG and drag RWTH VPN into Applications.
  2. Open it once. macOS blocks it, because the app is not notarized.
  3. Go to System Settings → Privacy & Security and click Open Anyway.

macOS 15 removed the old “right-click → Open” shortcut. The install guide shows the exact dialogs. On macOS 14, right-click → Open still works.

First run

  • Settings → username, VPN password, token secret (optional — otherwise type the code there before connecting).
  • Click Install… once. A small root-owned helper is installed; after that, connecting never asks for an admin password.
  • Connect. A shield appears in the menu bar while the tunnel is up.

Why

The official client is heavy and keeps asking for credentials and codes. This one keeps them in the Keychain, generates the TOTP code, and connects with one click. Split tunnel by default, so your local network keeps working.
